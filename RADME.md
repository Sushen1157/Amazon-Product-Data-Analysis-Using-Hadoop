## Project Overview

This project focuses on analyzing a large Amazon product dataset using Hadoop ecosystem technologies.

The project uses Hadoop HDFS, Apache Pig, and Java MapReduce to process and analyze approximately 1.4 million Amazon product records.


## Technologies Used

- Hadoop HDFS
- Apache Pig
- Java MapReduce
- Java


## Dataset

Dataset Name:

amazon_products.csv


Main Attributes:

- asin
- title
- stars
- reviews
- price
- category_id
- boughtInLastMonth


## Apache Pig Analysis

The following analyses were performed:

1. Rating Analysis
2. Review Analysis
3. Category Analysis
4. Price Analysis
5. Purchase Analysis


## MapReduce Analysis

The following MapReduce programs were developed:

1. Review Range Analysis
2. Top Price Analysis
3. Purchase Ranking Analysis
4. Product Popularity Analysis


## Project Structure

Dataset folder:
Contains Amazon product dataset.

Pig-Scripts folder:
Contains Apache Pig analysis scripts.

MapReduce folder:
Contains Java Mapper, Reducer, and Driver programs.

Output folder:
Contains generated Hadoop analysis results.

Report folder:
Contains final project report.
